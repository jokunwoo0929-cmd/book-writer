- **챕터별 Why-What 도입 문구**: 1장·2장·3장 각 챕터 첫머리의 "> 이 챕터를 읽어야 하는 이유" 구조는 독자 이해를 돕는 핵심 장치이므로 삭제하거나 형식을 바꾸지 말 것.
- **일상 비유 전체**: 파도, 강물, 기어 변속, 수문, 저수지, 선풍기, 형광등 비유는 모두 유지. 교체 또는 삭제 불가.
- **각 챕터 3단(도입-본론-정리) 흐름**: 수정 작업 중 이 구조를 훼손하지 말 것.
- **2.2절 통합 요약 문장**: "SMPS는 고주파 스위칭으로 에너지를 잘게 쪼개고, 트랜스포머로 전압을 변환한 뒤..."로 시작하는 요약 문장은 챕터 학습 정리 효과가 높으므로 유지.
- **출처 병기 관행**: 수정 과정에서 기존 출처 표기를 임의로 제거하지 말 것. `*(출처: researcher 정리 자료)*` 한 건만 교체 대상이다.

## reviewer → editor 특별 전달 사항

1. **현행 v2 원고는 사실 오류 0건이다.** editor는 사실 수정이 아닌 문체·구조·완성도 개선에 집중할 수 있다.

2. **[검증 필요] 태그는 단순 삭제가 아니라 본문 편입이 원칙이다.** 태그 안의 내용("CE 마크는 제품 유형에 따라 제3자 검증이 추가될 수 있으며 세부 절차는 제품군마다 다르다")은 사실로 검증된 정보이므로, 삭제하지 말고 괄호 주석이나 문장으로 본문에 통합해야 한다.

3. **소제목 형식 통일 항목은 이전 편집 주기에서 반영 기록이 있으나 실제 원고에서 확인되지 않는다.** 이 항목은 단순 누락일 수 있으므로 원고 전체 소제목을 재검토한 후 처리 방향을 결정할 것.

4. **세부 검토 의견은 `.claude/skills/workflows/review-report.md`의 "v2 editor 수정 반영본 재검토" 섹션에 챕터별로 기록되어 있다.** 권고 수정 항목에 대한 구체적인 예시 표현이 필요하면 해당 파일을 참조할 것.

5. **인덕터(코일) 누락 항목은 이전 편집 주기에서 editor 범위 초과로 판단하여 미처리 상태이다.** 이번 편집 주기에서도 2.2절 구조 재작성 없이는 처리가 어렵다면 중앙 관리자에게 writer 위임 여부를 확인할 것.
