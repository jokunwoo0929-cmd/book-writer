# 인수인계: researcher → writer

> 이 파일의 목적: writer가 초고 작성에 필요한 핵심 수치·비유·주의 사항만 전달한다. 전체 조사 노트(`.claude/skills/workflows/research-notes.md`)를 읽지 않아도 작성을 시작할 수 있도록 압축한다.
>
> 독자(대학교 1~2학년생)가 수식 없이 SMPS 원리를 이해하도록(Why) 비유 중심으로 서술하며, 각 챕터 첫머리에 Why 문장을 포함한다(What).

## 기본 정보

- 책 제목: 전기, 어렵지 않아요: SMPS로 배우는 스위칭 전원공급장치의 기본 원리
- 총 분량 목표: 약 1,500자 (챕터 1 약 600자, 챕터 2 약 600자, 챕터 3 약 300자)
- 집필 방침: 전문 수식 배제, 비유 중심 서술, 각 챕터 첫머리에 Why 문장 포함
- 상세 조사 자료: `.claude/skills/workflows/research-notes.md` (선택적 참조)

## 챕터별 핵심 전달 사항

### 챕터 1: 전원공급장치란 무엇인가 — 왜 변환이 필요한가

**사용 가능한 핵심 수치·사실**

| 항목 | 값 | 출처 |
|---|---|---|
| 한국 콘센트 전압 | AC 220V, 60Hz | 한국전력 공식 규격 (cyber.kepco.co.kr) |
| 스마트폰 충전기 출력 전압 | DC 5~9V | ASUS 지원 문서, USB 표준 |
| 노트북 어댑터 출력 전압 | DC 19~20V | ASUS 지원 문서 (asus.com) |
| LED 스트립 입력 전압 | DC 12V 또는 24V | LEDYi Lighting (ledyilighting.com) |
| LPS(선형 전원공급장치) 효율 | 30~60% [미확인-하한] | tutorialspoint.com, wevolver.com 교차 확인 |
| SMPS 효율 | 65~95% | tutorialspoint.com, electronicscoach.com 교차 확인 |

**추천 비유 소재**

- 직류(DC): "한쪽으로만 흐르는 강물" — 전자가 한 방향으로만 이동
- 교류(AC): "앞뒤로 반복되는 파도" — 초당 60회 방향이 바뀜(60Hz)
- LPS 발열: "입력 전압과 출력 전압의 차이를 전부 열로 태워 낮추는 방식" — 24V 입력에서 5V를 만들면 19V 분의 에너지가 열로 손실

**주의: 불확실한 정보**

- `[미확인]` LPS 효율 하한 수치: 출처에 따라 30~40% 또는 40~60%로 편차 존재. "일반적으로 30~60% 수준이며 조건에 따라 차이가 크다"는 보수적 표현 사용 권장. 단정하지 말 것.
- 기기 요구 전압은 제조사·모델별 편차 있으므로 "일반적인 예시"임을 명시할 것.

### 챕터 2: SMPS의 작동 원리 — 스위칭이 만드는 변환

**사용 가능한 핵심 수치·사실**

| 항목 | 값 | 출처 |
|---|---|---|
| SMPS 스위칭 주파수 (소비자용) | 일반적으로 50~500kHz | LCSC Blog, industrialmonitordirect.com |
| SMPS 스위칭 주파수 (최신) | 최대 1~2MHz | industrialmonitordirect.com |
| 역사적 진화 | 1980년대 20~40kHz → 2020년대 1~2MHz | industrialmonitordirect.com |
| PWM 듀티 사이클 원리 | ON 시간 비율이 클수록 평균 전압 상승, 작을수록 하강 | digikey.kr, ktword.co.kr |
| 트랜스포머 소형화 원리 | 주파수 높을수록 코어·권선 크기 감소. 60Hz 상용 변압기 대비 50kHz 이상 SMPS 트랜스포머는 수십 배 소형 | namu.wiki/SMPS, electronicmanufacturingservice.org |

**추천 비유 소재**

- PWM: "선풍기 ON/OFF를 초당 수만 번 반복하면 중간 속도처럼 느껴진다. SMPS는 이 원리로 출력 전압을 조절한다."
- 트랜스포머: "코일 감은 수를 조절하는 것은 기어 변속처럼 전압(힘)을 바꾸는 것."
- 다이오드: "물이 한쪽으로만 흐르는 일방통행 수문 — 교류를 직류로 변환하는 정류 역할."
- 캐패시터: "전기 저수지 — 전압이 높을 때 충전하고, 낮을 때 방전하여 출력 전압을 평탄하게 유지."

**주의: 불확실한 정보**

- 스위칭 주파수 범위는 제품 유형과 설계에 따라 매우 다양하므로 "일반적으로" 또는 "소비자용 제품 기준"이라는 단서를 반드시 붙일 것.
- 스위칭 주파수 상승에 따른 소형화는 스위칭 손실 증가라는 trade-off가 있음. 입문 수준 본문에서는 "높은 주파수 덕분에 작아질 수 있다"는 핵심 메시지만 전달하고, 손실 trade-off는 주석·부연으로 처리 가능.

### 챕터 3: SMPS의 응용과 안전 — 생활 속 전원공급장치

**사용 가능한 핵심 수치·사실**

| 항목 | 값 | 출처 |
|---|---|---|
| SMPS 주요 응용 제품 (5가지) | 스마트폰 충전기, 노트북 어댑터, PC 파워서플라이, LED 조명 전원, 인터넷 공유기·셋톱박스 | nalayang.com, cnnvvv.com |
| EMI 전도성 경로 | 전원 배선·회로를 통해 전파 | elementkorea.kr |
| EMI 방사성 경로 | 공기 중으로 방사. 거리·차폐 상태에 따라 강도 차이 | elementkorea.kr |
| KC 인증 | 한국 시장 판매 필수. 시험 기관 검증 방식 | ufinebattery.com/ko, elementkorea.kr |
| CE 마크 | EU 시장 진입 필수. 제조사 자기 선언 방식 | ufinebattery.com/ko |
| UL 인증 | 미국 시장 사실상 필수. 제3자 독립 기관 검증. 세 인증 중 가장 엄격 | ufinebattery.com/ko, tonful.com |

**추천 비유 소재**

- EMI: "SMPS가 초당 수만 번 스위칭할 때 생기는 전자기 잡음은 형광등 켤 때 라디오에 끼는 잡음과 같다."
- 인증 마크: "충전기 뒷면에 KC·CE·UL 마크가 있다면, 각 나라의 안전 기준을 통과했다는 증거다."

**주의: 불확실한 정보**

- CE 마크는 자기 선언 방식이 기본이나 제품 유형에 따라 제3자 검증이 추가될 수 있음. "제조사가 유럽 기준을 충족했다고 선언한 마크"라고 간략히 표현하고 세부 절차는 생략 권장.
- UL "법적 의무 아니나 사실상 필수"는 업계 관행 기반 표현이므로, 단서 없이 단정하지 말 것.

## researcher → writer 특별 전달 사항

1. **분량 배분 엄수**: 챕터 1 약 600자, 챕터 2 약 600자, 챕터 3 약 300자. 전체 합계 약 1,500자 목표.
2. **비유 우선 서술**: 수치를 제시할 때 반드시 비유로 풀어서 설명한다. 수치만 나열하지 말 것.
3. **Why 문장 필수**: 각 챕터 첫머리에 "이 챕터를 읽어야 하는 이유(Why)"를 한 문장으로 명시한다.
4. **[미확인] 항목 처리**: LPS 효율 하한 수치는 범위 표현("30~60%")을 사용하고 "조건에 따라 차이가 있다"는 단서를 병기한다.
5. **인증 마크 서술**: KC·CE·UL 설명은 독자가 제품 구매 시 직접 확인할 수 있는 실용적 맥락으로 서술한다.
6. **출처 표기**: 수치·통계 인용 시 출처를 인라인 또는 각주로 표기한다.
