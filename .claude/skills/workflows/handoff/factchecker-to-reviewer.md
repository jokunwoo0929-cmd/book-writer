## fact-checker → reviewer 특별 전달 사항

1. **현행 v2 원고는 사실 오류 0건**이다. reviewer는 사실 검증 관련 수정 작업 없이 논리 구조·문체 일관성·가독성·완성도 검토에 집중할 수 있다.

2. **[검증 필요] 태그가 3.2절에 1건 잔존한다.** 이 태그는 editor의 수정 작업에서 누락된 것으로 보인다. reviewer는 이 태그를 검토 의견에 반드시 포함하고, editor 또는 직접 처리 권고를 전달해야 한다.

3. **조건부 정확 4건은 단서 병기로 이미 완화 처리되어 있다.** 별도 수정 의무는 없으나, reviewer가 독자 친화성 관점에서 추가 표현 정밀화를 권고하는 것은 재량 범위 내이다.

4. **이전 v1에서 지적된 주요 수정 사항 3건(노트북 전압, LPS 효율, 전자레인지 비유)은 모두 v2에서 올바르게 반영되었음을 확인했다.** 해당 항목들을 재검토할 필요는 없다.

5. **세부 검증 보고서는 `.claude/skills/workflows/fact-check-report.md`에 챕터별로 기록되어 있다.** 필요 시 출처 URL 및 구체적인 판정 근거를 참조할 수 있다.
