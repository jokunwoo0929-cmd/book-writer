## publisher가 알아야 할 특이 사항

### 잔여 미확인 항목
- 없음. 사실 오류 0건, `[검증 필요]` 태그 0건, `[미확인]` 항목 0건.

### 포맷 주의 사항

1. **소제목 형식**: 전체 소제목이 의문문(~는가, ~는가?, ~인가 형식)으로 통일되었다. 목차와 본문 소제목 텍스트가 동일하게 맞춰져 있으므로, 포맷 변환 시 어느 한쪽도 누락하지 않도록 주의.

2. **볼드 처리 기준**: 핵심 전문 용어(교류, 직류, 스위칭, PWM, 듀티 사이클, 트랜스포머(변압기), 다이오드, 캐패시터(축전기), 정류, KC 마크, CE 마크, UL 마크, EMI)에 볼드 처리 되어 있다. 포맷 변환 시 볼드 처리 유지 확인 필요.

3. **출처 표기 형식**: `*(출처: ...)*` 형식으로 이탤릭 처리된 출처 표기가 본문 내 여러 곳에 남아 있다. publisher는 이를 각주 또는 미주로 전환할지 원문 유지할지 결정 필요.

4. **목차와 본문 동기화**: 목차 섹션(파일 상단)과 본문 소제목이 동일하게 통일되어 있다. TOC.md 별도 파일 생성 시 이 목차 섹션을 기준으로 사용할 것.

5. **챕터 Why-What 도입 문구**: 각 챕터 첫머리의 `> 이 챕터를 읽어야 하는 이유: ...` 인용 블록은 유지 권고 항목이다. 포맷 변환 시 삭제하지 말 것.

6. **메타데이터**: 파일 상단 YAML 프론트매터(`version: 3.0.0`, `status: editing-complete`)가 포함되어 있다. 출판 포맷에 따라 해당 헤더 처리 방식(포함 여부) 결정 필요.

### 차기 버전 권고 사항 (publisher는 직접 수정하지 말고 기록만 할 것)

1. **인덕터(코일) 항목 추가**: 2.2절에서 트랜스포머·다이오드·캐패시터와 함께 인덕터(코일)의 역할을 설명하는 내용이 누락되어 있다. 2.2절 구조 재작성 수준이므로 writer에게 위임 필요. 중앙 관리자 확인 권고.

2. **USB-A/USB-C PD 보충 설명**: 1.1절에서 스마트폰 충전 전압을 "DC 5~9V(일반 USB-A 기준)"으로 표기했으나, USB-C PD 규격의 20V 이상 영역에 대한 추가 설명이 있으면 독자 이해에 도움이 될 것.

3. **전체 결론 단락**: 3장 끝에 전체 내용을 아우르는 맺음말이 없다(라운드 1에서 추가 기록이 있으나 현행 v3 원고에 별도 맺음말 단락이 존재하지 않음). 2판 작업 시 추가 검토 권고.
