이 단계는 편집이 완료된 원고를 출판 규격에 맞게 다듬고 최종 결과물을 생성하는 과정이다.

## STEP 7: 출판 (publisher)

### 담당 에이전트
`publisher`

### 입력 자료
- `.claude/skills/workflows/handoff/editor-to-publisher.md` — 편집 완료 상태·포맷 주의 사항
- `editor`가 수정한 최종 원고 (`output/BOOK.md`)
- 수정 내역 로그 (`.claude/skills/workflows/edit-log.md`) — 선택

### 작업 순서

#### 7-1. 최종 품질 점검
1. `output/BOOK.md`를 전체 통독하며 아래 항목을 최종 점검한다.
   - 제목, 소제목, 본문의 서식 일관성
   - 문장 부호, 띄어쓰기, 맞춤법
   - 목차와 실제 챕터 제목·순서의 일치 여부
   - 각주·출처 표기의 누락 여부
2. 점검 결과를 `.claude/skills/workflows/final-check.md`에 기록한다.

#### 7-2. 포맷 정리
3. 목차를 자동 참조 가능한 형태로 정리한다 (Markdown 앵커 링크).
4. 챕터 번호와 소제목 번호가 순서대로 매겨졌는지 확인하고 수정한다.
5. 인용·출처를 일관된 형식(본문 내 인용 또는 미주)으로 통일한다.
6. 필요시 용어 목록(glossary), 참고 문헌 섹션을 추가한다.

#### 7-3. 출판본 생성
7. 포맷 정리가 완료된 내용으로 `output/BOOK.md`를 최종 업데이트한다.
8. 책의 첫 페이지에 다음 정보를 포함한다.
   - 제목 및 부제
   - 작성 날짜
   - 에이전트 협업 시스템으로 작성되었음을 나타내는 표기
9. `output/TOC.md`에 목차(챕터 제목 + 소제목 + 앵커 링크)를 별도 파일로 저장한다.
10. `output/SUMMARY.md`에 챕터별 1~2문장 요약을 작성하여 저장한다.
11. 작업 기록을 이 파일(`03-finalize.md`) 하단에 추가한다.

### 출력 파일
- `output/BOOK.md` — 최종 출판본 (포맷 완성)
- `output/TOC.md` — 목차 독립 파일
- `output/SUMMARY.md` — 챕터별 요약 파일
- `.claude/skills/workflows/final-check.md` — 최종 점검 결과
- 이 파일(`03-finalize.md`) 하단에 작업 기록 추가

### 완료 조건
- [x] 목차와 본문 챕터 구조가 완전히 일치한다.
- [x] 서식(제목 레벨, 번호, 들여쓰기)이 전체에 걸쳐 일관된다.
- [x] 인용·출처 표기가 누락 없이 통일된 형식으로 작성되어 있다.
- [x] `output/TOC.md`와 `output/SUMMARY.md`가 생성되었다.
- [ ] 최종 점검 결과 파일이 존재한다.
- [ ] 중앙 관리자가 최종본을 확인하고 출판 완료를 선언하였다.

### 반려 조건 및 재작업 절차
중앙 관리자가 아래 사유 중 하나를 발견하면 `publisher`에게 반려한다.
- 목차와 본문 챕터 제목이 불일치하는 경우
- 서식이 챕터마다 다르게 적용된 경우
- 사실 오류 또는 `[미확인]` 항목이 본문에 남아 있는 경우

단, 내용상 오류(사실 오류, 논리 결함)가 발견되면 `publisher`가 직접 수정하지 않고 중앙 관리자에게 보고한다. 중앙 관리자는 오류의 성격에 따라 해당 단계의 에이전트에게 재작업을 지시한다.

## 단계 간 롤백(Roll-back) 절차

출판 단계에서 이전 단계의 문제가 발견될 경우 아래 절차를 따른다.

| 발견된 문제 유형 | 롤백 대상 에이전트 | 처리 방법 |
|---|---|---|
| 사실 오류 | `fact-checker` → `editor` | 재검증 후 재편집 |
| 논리 구조·문체 문제 | `reviewer` → `editor` | 추가 검토 의견 작성 후 재편집 |
| 조사 자료 부족 | `researcher` → `writer` → `editor` | 보완 조사 후 해당 챕터 재작성 및 재편집 |
| 목차 구조 문제 | `planner` → 이후 전 단계 | 목차 수정 후 영향을 받는 챕터 전체 재작업 |

롤백 시 중앙 관리자는 다음을 명시한다.
1. 롤백 대상 에이전트와 이유 (Why)
2. 재작업이 필요한 구체적인 범위 (챕터, 항목)
3. 재작업 완료 후 재개해야 할 단계
